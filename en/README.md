# Docsify Starter

> A minimal Docsify v5 starter with Chinese / English switching.

This is the English homepage. English docs live under `en/`, mirroring the root structure.

- Plain Markdown, no build step
- Sidebar, navbar, cover, full-text search, previous / next, 404
- Dark mode and a bottom-right language switch
- Local assets, no CDN dependency
